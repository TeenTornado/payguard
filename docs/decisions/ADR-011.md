# ADR-011: Two-tier (curated rules + train-split examples) grounding KB

**Status:** Accepted
**Date:** 2026-08-24

## Context

The LLM analyzer over-flags on this corpus (on the frozen test split, System C's macro precision
is 0.485 — the LLM adds ~17 false positives on WEBHOOK_INTEGRITY/AMOUNT_CURRENCY that static does
not). We want to ground the analyzer in retrieved evidence to cut those false positives. Two
tempting shortcuts exist: (a) dump the entire Razorpay documentation into a vector store, or (b)
skip retrieval and inline every rule/example into the prompt.

## Decision

The KB has exactly two tiers:

- **RULE tier** — a small, hand-curated set of authoritative Razorpay facts
  (`docs/reference/razorpay-facts.md`, one chunk per rule), each tagged with the defect class it
  grounds. These are the ground truth the detectors already encode (raw-body HMAC, event-id dedup,
  amount-in-paise, etc.).
- **EXAMPLE tier** — labeled snippets from the dataset's TRAIN split, each stored as a
  SAFE_PATTERN or UNSAFE_PATTERN with its defect class and `sample_id`; hard negatives up-weighted.

Retrieval fuses dense + lexical over both tiers, filtered by defect class, and always surfaces a
citable RULE.

## Alternatives rejected

- **Full doc-dump.** Indexing all of Razorpay's docs adds mostly-irrelevant chunks (rate limits,
  UI SDKs, dashboards) that dilute retrieval and mislead a weak model. Curated facts keep the
  RULE tier authoritative and small.
- **Inline everything, no retrieval.** Inlining every rule + example makes the prompt enormous
  (already ~6 KB with 2 chunks/class on a 7B model); it does not scale as the corpus grows and
  gives the model no signal about which evidence is *relevant to this code*. Retrieval selects the
  few chunks that matter and keeps the prompt affordable.

## Consequences

- The KB is auditable (a human can read the 11 rules) and grows with the labeled dataset.
- Grounding quality is bounded by the curation of the RULE tier and the coverage of TRAIN examples.
- The two-tier design lets the prompt cite a specific rule and point at labeled precedents.
